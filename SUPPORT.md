# Getting help

- **Using the GaiaDesk apps:** email [support@gaiadesk.net](mailto:support@gaiadesk.net), or visit [gaiadesk.net](https://gaiadesk.net).
- **Downloads:** [gaiadesk.net/download](https://gaiadesk.net/download).
- **SDK or MCP server questions and bugs:** open an issue in [gaiadesk-mcp](https://github.com/Gaia-Desk/gaiadesk-mcp/issues), [gaiadesk-typescript](https://github.com/Gaia-Desk/gaiadesk-typescript/issues) or [gaiadesk-python](https://github.com/Gaia-Desk/gaiadesk-python/issues).
- **Security issues:** [security@gaiadesk.net](mailto:security@gaiadesk.net). Please don't post them publicly.
